# 말이 통하는 카드키 · 모아스테이 룸키

외국인 숙박객이 NFC 카드키를 휴대폰에 대면 열리는 숙소 AI 도우미입니다. Figma 디자인(손님 화면 11개 + 사장님 화면)을 그대로 코드로 옮겼습니다.

- 손님 화면: `https://내주소/k/카드토큰` (시연용 `/k/demo203`, 만료 카드 예시 `/k/demo105`)
- 사장님 화면: `https://내주소/owner` (PIN 로그인)

## 1. 로컬에서 먼저 보기 (선택)
```bash
npm install
npm run dev        # http://localhost:3000/k/demo203 , http://localhost:3000/owner (PIN 0000)
```
API 키가 없으면 미리 준비한 **데모 답변**으로 돌아갑니다. 실제 GPT로 보려면 `.env.example`을 `.env.local`로 복사해 키를 넣으세요.

## 2. Vercel에 배포하기
1. 이 폴더를 GitHub 저장소에 올립니다. (`.env.local`, `node_modules`는 `.gitignore`로 빠집니다)
2. vercel.com → **Add New → Project** → 저장소 선택 → Framework는 **Other** 그대로 → **Deploy**
3. 저장소(대화·알림 보관) 연결: 프로젝트 → **Storage** 탭 → **Upstash (Redis)** 선택 → 무료 플랜으로 만들고 프로젝트에 연결
   - 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN`이 자동으로 들어갑니다. **이걸 안 하면 손님 화면과 사장님 화면이 서로 대화를 못 봅니다.**
4. **Settings → Environment Variables**에 추가
   | 이름 | 값 |
   |---|---|
   | `OPENAI_API_KEY` | OpenAI 키 (platform.openai.com → API keys) |
   | `OPENAI_MODEL` | 쓸 모델 이름. 비워 두면 `gpt-5.4-mini` |
   | `OWNER_PIN` | 사장님 화면 비밀번호 (예: 숫자 6자리) |
5. **Deployments → 최신 배포 → Redeploy** (환경변수는 다시 배포해야 적용됩니다)
6. `/owner` 맨 아래에 "OpenAI 연결됨 · Redis 연결됨"이 보이면 완료

> API 키는 채팅·카톡·GitHub에 붙여넣지 말고 Vercel 환경변수에만 넣으세요.

## 3. NFC 카드키 만들기
1. 사장님 화면 → **새 카드 발급**: 객실 번호, 예약자 성(영문), 체크아웃 시간 입력 → 주소 생성
   (시연은 기본 카드 `https://내주소/k/demo203`을 써도 됩니다. 예약자 성: TANAKA)
2. 휴대폰에 **NFC Tools** 앱 설치 → 쓰기 → 레코드 추가 → URL → 주소 붙여넣기 → NFC 스티커(NTAG213/215)를 휴대폰 뒷면에 대기
3. 아이폰은 잠금 해제 상태에서 카드에 대면 알림이 뜨고, 안드로이드는 NFC를 켜 두면 바로 열립니다.
4. 체크아웃하면 사장님 화면 **체크아웃 처리** → 그 카드는 바로 만료 화면만 보여 줍니다.

## 4. 시연 영상 찍는 순서 (추천)
1. 사장님 화면 맨 아래 **시연 데이터 초기화**
2. 휴대폰 A(손님): 카드키 탭 → 日本語 선택 → 홈
3. "お湯が出ない" → 단계 안내 → **いいえ、まだ冷たい** → 성 `TANAKA` → 오너 연락 완료 화면
4. 휴대폰 B 또는 노트북(사장님): 알림 도착(알림음) → **손님에게 답장** → "지금 올라갈게요. 5분만 기다려 주세요."
5. 휴대폰 A에 "今すぐ伺います。5分ほどお待ちください。"가 4초 안에 표시
6. AI 질문: 짐 보관 / 약국 / 매뉴얼에 없는 질문(SIM 카드) → 사장님 연결 버튼까지
7. 만료 카드(`/k/demo105`) 화면으로 보안 설명

## 구조
```
api/            Vercel 서버리스 함수
  card.js       카드 확인(만료 여부) · 손님에게 보여 줄 정보만 반환
  ask.js        GPT 답변 (매뉴얼 근거, 구조화 출력)
  escalate.js   본인 확인 → 사장님 알림(한국어 요약)
  thread.js     대화·사장님 답장 가져오기 (손님 화면이 4초마다 확인)
  owner.js      사장님 화면 API (PIN 필요)
lib/            저장소(Redis/메모리), OpenAI 호출, 데모 답변, 카드·알림
promptpack/     매뉴얼 JSON · 프롬프트 원본 → 고친 뒤 `npm run pack`
public/         화면 (index.html 손님, owner.html 사장님)
```

## 보안 메모
- 카드에는 무작위 토큰 주소만 들어갑니다. 객실 번호·이름·도어락 정보는 카드와 AI 데이터에 없습니다.
- 예약자 성은 서버에만 있고 손님 화면으로 보내지 않습니다.
- 모아스테이는 가상 숙소입니다. 119·112·1330만 실제 번호입니다.
